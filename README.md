# cad-tools

Small scripts and add-ins that take the repetitive work out of CAD.

> [!TIP]
> **Have parts that need cutting?** Head over to [Upstate CNC](https://upstatecnc.com) to get an instant quote for CNC-cut wood parts.

### Fusion

- [Batch STEP Export](fusion/BatchExportSTEP/) - saves every part in a Fusion design as its own `.step` file in one click, one file per component or per body.
